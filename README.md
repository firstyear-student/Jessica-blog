# Jessica Keneo Letsapa | Reflective Blog & Portfolio

A personal reflective blog and digital portfolio built with HTML, CSS and JavaScript.
It brings together my CV, reflective posts, group experience, projects, application letter and email, and study tips as a first-year Business Intelligence and Data Analytics student at the Botswana School of Business Sciences.

## Sections

- **Home & About:** introduction and key numbers
- **CV:** profile, education, experience and skills
- **Reflection:** my first year, in four short steps
- **Group Experience:** photos and reflection on working in a team
- **Skills & Projects:** technical and professional skills, plus my projects
- **Application Letter & Email:** ready-to-copy internship/attachment templates
- **Study Tips & Resources:** how I learn best and the tools I use

## How to view

1. Download or clone this repository.
2. Open `index.html` in any web browser.

Or view it online with GitHub Pages: **Settings → Pages → Branch: main → / (root) → Save**.
